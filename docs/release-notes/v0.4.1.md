다중분광 결과에서 만들 식생·수분 지수를 사용자가 고르게 한 릴리스임.

## 설치 파일

| OS | 파일 |
|---|---|
| macOS 14 이상 (Apple Silicon) | `QuickOrtho_0.4.1_aarch64.dmg` |
| Windows 10/11 (64비트) | `QuickOrtho_0.4.1_x64-setup.exe` 또는 `QuickOrtho_0.4.1_x64_en-US.msi` |

설치 방법은 [사용 매뉴얼](https://github.com/SeaViewer91/quick-ortho/blob/main/docs/MANUAL.md)을 참고함. macOS는 설치 후 터미널에서 다음을 한 번 실행해야 함.

```bash
xattr -dr com.apple.quarantine /Applications/QuickOrtho.app
```

## 개선

- **지수 선택**: 다중분광 폴더를 불러오면 `식생·수분 지수` 칸에서 만들 지수를 고름. 고른 것만 만들고, 마지막 선택을 기억함 (처음 기본값 NDVI·NDRE·GNDVI)
- **지수 추가**: NDWI(수면), OSAVI·SAVI(토양 보정), EVI, CIre·CIg(엽록소). 카메라에 필요한 밴드가 없는 지수는 고를 수 없음
- **지수만 다시 만들기**: 정사 모자이크 결과 칸의 `식생지수 다시 만들기`로 정렬·정사 모자이크를 다시 하지 않고 지수만 바꿔 만듦 (수십 초)
- **지도 지수 레이어**: 만든 지수 중 하나를 골라 지도에 표시하고, 지수별 색 범위 범례를 보여 줌

## 바뀐 점 (주의)

- 지수 파일이 `indices.tif` 한 파일(여러 밴드)에서 `indices/<지수>.tif` 지수별 파일로 바뀜. v0.4.0 결과 폴더는 지수를 다시 만들면 새 형식으로 바뀜
- 엔진 명령행: `ortho --indices NDVI,NDWI`, 새 명령 `indices <결과 폴더> --indices …`

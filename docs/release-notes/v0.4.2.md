사용 매뉴얼을 HTML로도 배포하는 릴리스임. 처리 결과는 v0.4.1과 같음.

## 설치 파일

| OS | 파일 |
|---|---|
| macOS 14 이상 (Apple Silicon) | `QuickOrtho_0.4.2_aarch64.dmg` |
| Windows 10/11 (64비트) | `QuickOrtho_0.4.2_x64-setup.exe` 또는 `QuickOrtho_0.4.2_x64_en-US.msi` |
| 사용 매뉴얼 (HTML) | `QuickOrtho_0.4.2_manual.html` |

설치 방법은 첨부한 매뉴얼 HTML 또는 [사용 매뉴얼](https://github.com/SeaViewer91/quick-ortho/blob/main/docs/MANUAL.md)을 참고함. macOS는 설치 후 터미널에서 다음을 한 번 실행해야 함.

```bash
xattr -dr com.apple.quarantine /Applications/QuickOrtho.app
```

## 개선

- **HTML 사용 매뉴얼**: `docs/MANUAL.md`와 같은 내용을 파일 하나짜리 HTML로 만들어 릴리스에 첨부함. 글꼴·스크립트를 외부에서 받지 않으므로 인터넷 없이 브라우저에서 열림
  - 왼쪽 목차(지금 읽는 절 표시), 명령어 복사 버튼, 어두운 화면 모드, 인쇄용 서식(목차 숨김)
  - 휴대폰 화면에서도 읽을 수 있음 (목차는 `목차` 버튼으로 펼침)
- **앱에서 매뉴얼 열기**: 앱 하단 `사용 매뉴얼`을 누르면 앱에 포함된 매뉴얼이 기본 브라우저로 열림. 현장에서 인터넷 없이 볼 수 있음

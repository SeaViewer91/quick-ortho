QuickOrtho 첫 사전 릴리스임. 현장 노트북에서 인터넷 없이 드론 영상의 촬영 상태를 확인하고 정사 모자이크를 만드는 데스크톱 앱임.

## 설치 파일

| OS | 파일 |
|---|---|
| macOS 14 이상 (Apple Silicon) | `QuickOrtho_0.1.0_aarch64.dmg` |
| Windows 10/11 (64비트) | `QuickOrtho_0.1.0_x64-setup.exe` 또는 `QuickOrtho_0.1.0_x64_en-US.msi` |

처리 엔진이 포함되어 있어 Python 등 별도 설치가 필요 없음. 코드 서명을 하지 않은 빌드이므로 설치 방법은 [사용 매뉴얼](https://github.com/SeaViewer91/quick-ortho/blob/main/docs/MANUAL.md)을 참고함.

macOS는 설치 후 터미널에서 다음을 한 번 실행해야 함.

```bash
xattr -dr com.apple.quarantine /Applications/QuickOrtho.app
```

## 주요 기능

- 데이터 불러오기: 사진 정보(EXIF/XMP)만으로 1초 안팎에 촬영 범위, 중복도, 누락 구역을 표시함
- 간이 모자이크: 영상을 대략 배치해 수 초 안에 촬영 결과를 눈으로 확인함
- 정사 모자이크: SfM(pycolmap) 기반으로 정합해 Cloud Optimized GeoTIFF(UTM)를 생성함
- 오프라인 동작, 처리 중단, 결과 폴더 열기

## 알려진 한계

- 실제 노트북 설치 검증 전의 사전 릴리스임
- 검증 기종은 DJI Mavic 2 Pro뿐임. Mavic 3E, Matrice 4E, Phantom 4 Pro V2.0은 검증 예정임
- 절대 위치 정확도는 GNSS 수준(수 m)이며 GCP 보정은 아직 지원하지 않음
- 간이 DSM을 사용하므로 고층 건물은 옆면이 보이거나 약간 겹쳐 보일 수 있음
- NVIDIA GPU 가속은 아직 지원하지 않음 (CPU로 처리)

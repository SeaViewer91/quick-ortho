v0.2.0의 오류를 고친 수정 릴리스임. Windows에서 PostGIS 등 GIS 프로그램이 설치된 노트북에서 정사 모자이크가 실패하던 문제를 고쳤고, 정렬을 마친 뒤 실패한 작업을 이어서 끝낼 수 있게 함.

## 설치 파일

| OS | 파일 |
|---|---|
| macOS 14 이상 (Apple Silicon) | `QuickOrtho_0.2.1_aarch64.dmg` |
| Windows 10/11 (64비트) | `QuickOrtho_0.2.1_x64-setup.exe` 또는 `QuickOrtho_0.2.1_x64_en-US.msi` |

설치 방법은 [사용 매뉴얼](https://github.com/SeaViewer91/quick-ortho/blob/main/docs/MANUAL.md)을 참고함. macOS는 설치 후 터미널에서 다음을 한 번 실행해야 함.

```bash
xattr -dr com.apple.quarantine /Applications/QuickOrtho.app
```

## 고친 문제

- **PostGIS·QGIS가 설치된 PC에서 정사 모자이크 실패**: 정렬을 마친 뒤 `The EPSG code is unknown ... It comes from another PROJ installation` 오류로 끝나던 문제. PostGIS 설치 프로그램이 시스템 환경변수 `PROJ_LIB`를 자기 폴더로 설정해, 엔진이 버전이 다른 좌표계 DB(`proj.db`)를 읽은 것이 원인임. 엔진이 앱에 들어 있는 데이터만 쓰도록 바꿈. 시스템 설정과 PostGIS 동작에는 영향이 없음
- **처리 중 엔진이 드물게 종료되던 문제**: 특징점 추출·매칭 진행률을 읽는 방식이 처리 엔진(COLMAP)의 DB 쓰기와 겹치면 `database is locked`로 종료될 수 있었음. 잠금을 잡지 않는 방식으로 바꿈. 영상이 많아 처리 시간이 길수록 생기기 쉬웠음

## 개선

- **정렬 결과로 정사 모자이크 만들기**: 정렬(전체 처리 시간의 70~75%)을 마친 뒤 실패·중단된 폴더를 불러오면 이 버튼이 표시되고, 정렬을 다시 하지 않고 정사 모자이크만 만듦. v0.2.0에서 위 오류로 실패한 폴더도 이어서 만들 수 있음
- 실패한 작업이 남긴 SfM 작업 폴더(`ortho/work`, 영상 수백 장이면 수 GB)를 자동으로 지움
- 이전·이후 버전이 만든 결과 폴더를 열 때 보고서에 값이 빠져 있어도 화면이 멈추지 않음

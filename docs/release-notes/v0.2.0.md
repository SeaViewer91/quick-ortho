정밀 보정 기능을 추가한 사전 릴리스임. GCP 측량 성과로 좌표를 보정하고, 타이포인트를 추가·정리해 정합 오차를 낮출 수 있음.

## 설치 파일

| OS | 파일 |
|---|---|
| macOS 14 이상 (Apple Silicon) | `QuickOrtho_0.2.0_aarch64.dmg` |
| Windows 10/11 (64비트) | `QuickOrtho_0.2.0_x64-setup.exe` 또는 `QuickOrtho_0.2.0_x64_en-US.msi` |

설치 방법은 [사용 매뉴얼](https://github.com/SeaViewer91/quick-ortho/blob/main/docs/MANUAL.md)을 참고함. macOS는 설치 후 터미널에서 다음을 한 번 실행해야 함.

```bash
xattr -dr com.apple.quarantine /Applications/QuickOrtho.app
```

## 새 기능

- GCP 보정
  - 측량 성과 파일(CSV·TXT) 불러오기: 인코딩(UTF-8, CP949)·구분자 자동 판단, 열 지정, 좌표계 선택(국내 TM·UTM-K·UTM·WGS84 경위도, EPSG 직접 입력)
  - 촬영 위치와 비교해 좌표계와 X/Y 순서를 자동으로 추정함
  - GCP가 보일 사진과 위치를 예측해 확대 조각으로 보여주고, 사진을 클릭해 표시함
  - 기준점·검사점 구분, 검사점 RMSE(X, Y, Z) 보고
  - GCP 좌표계로 정사 모자이크를 저장함
- 수동 타이포인트: 지도에서 위치를 고르고 사진 2장 이상에 표시해 연결을 보강함
- 오차 정리: 점별·사진별 재투영 오차, 오차 분포, 자동 제거 기준별 제거량 미리보기, 점 선택 삭제
- 보정 실행 후 재투영 RMSE 변화와 GCP 오차 표시, 최초 결과로 되돌리기
- 정사 모자이크를 만든 폴더를 다시 불러오면 이전 결과를 함께 표시함

## 변경 사항

- 정사 모자이크 결과 폴더에 보정용 `project/` 폴더가 생김 (영상 수에 따라 수~수십 MB)

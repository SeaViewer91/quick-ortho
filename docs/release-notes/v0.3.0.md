정사 모자이크의 화질을 높인 릴리스임. 결과를 원본 해상도로 만들고, 영상을 평균하지 않고 한 장씩 골라 붙이는 심라인 합성으로 바꿔 상이 여러 개 겹쳐 보이던 문제를 없앰.

## 설치 파일

| OS | 파일 |
|---|---|
| macOS 14 이상 (Apple Silicon) | `QuickOrtho_0.3.0_aarch64.dmg` |
| Windows 10/11 (64비트) | `QuickOrtho_0.3.0_x64-setup.exe` 또는 `QuickOrtho_0.3.0_x64_en-US.msi` |

설치 방법은 [사용 매뉴얼](https://github.com/SeaViewer91/quick-ortho/blob/main/docs/MANUAL.md)을 참고함. macOS는 설치 후 터미널에서 다음을 한 번 실행해야 함.

```bash
xattr -dr com.apple.quarantine /Applications/QuickOrtho.app
```

## 개선

- **상 겹침(고스팅) 제거**: 지금까지는 한 지점을 덮는 영상 여러 장을 가중 평균했음. 간이 DSM의 높이가 실제와 다르면(수면, 갈대, 부표·통 같은 작은 물체) 영상마다 투영 위치가 조금씩 달라 물체가 여러 개로 흐리게 겹쳐 보였음. 이제 화소마다 영상 중심에 가장 가까운 영상 하나를 골라 쓰고, 영상이 바뀌는 경계의 몇 화소만 섞어 이음매를 감춤(심라인 합성)
- **원본 해상도 출력**: 결과 GSD를 원본 영상 GSD와 같게 함 (기존은 2배). 지붕 위 태양광 패널, 차량, 차선이 선명해짐
- **간이 DSM 개선**: 격자를 더 촘촘하게 하고 평활화를 줄여 지형·건물 높이 변화를 더 잘 따라가게 함. 두 영상 간 국소 상관(NCC)으로 평가한 정합 일관성이 Mavic 2 표본에서 0.78에서 0.84로 높아짐
- 정밀 보정에서 다시 만드는 정사 모자이크도 원본 해상도·심라인 합성으로 만듦 (이전 버전에서 만든 결과 폴더 포함)

## 바뀐 점 (주의)

- 원본 해상도로 만들므로 정사 모자이크 단계가 v0.2.x보다 2~3배 걸리고, 결과 파일이 약 4배 커짐
  - Aukerman 77장(18MP): 정사투영 73초 → 187초, 결과 16510×13758px 약 318MB, 피크 메모리 약 2.6GB (2코어 VM)
- 영상이 수백 장이면 결과 파일이 수 GB가 될 수 있음. 작업 중 임시 파일이 함께 생기므로 결과 예상 크기의 2배 이상 디스크 여유를 확보함
- 심라인 합성은 영상이 바뀌는 경계에서 높이가 불확실한 물체(수면, 갈대, 고층 건물 지붕선)가 약간 끊겨 보일 수 있음. 겹쳐 흐려지는 것보다 판독에 유리함
- 엔진 명령행의 `--gsd-scale` 기본값이 2.0에서 1.0으로 바뀜. 이전처럼 만들려면 `--gsd-scale 2`를 지정함

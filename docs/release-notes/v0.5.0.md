바다·호수가 찍힌 비행을 위한 수면 처리를 추가한 릴리스임. 수면을 물가 높이의 평면으로 처리해 수면에서 생기던 어긋남을 줄임.

## 설치 파일

| OS | 파일 |
|---|---|
| macOS 14 이상 (Apple Silicon) | `QuickOrtho_0.5.0_aarch64.dmg` |

설치 방법은 첨부한 매뉴얼 HTML 또는 [사용 매뉴얼](https://github.com/SeaViewer91/quick-ortho/blob/main/docs/MANUAL.md)을 참고함. macOS는 설치 후 터미널에서 다음을 한 번 실행해야 함.

```bash
xattr -dr com.apple.quarantine /Applications/QuickOrtho.app
```

## 새 기능

- **수면 처리** (`정사 모자이크 생성` 위 `수면 처리`: 자동 / 켬 / 끔, 마지막 선택 기억)
  - 자동(기본)은 영상 면적의 5% 이상이 수면이면 켬. `끔`은 v0.4 이전과 같은 처리
  - 수면 판별: 세밀한 질감이 없고 푸르거나 청록인 넓은 영역을 찾고, 이어진 해초 띠·그늘진 물까지 포함함
  - 특징점 제외: 넓고 확실한 수면 안쪽의 특징점을 빼서 파도·반사 무늬가 영상당 특징점 수를 차지하지 않게 함 (물가 띠는 남김)
  - 수면 평면: 간이 DSM이 수면을 주변 육지(방파제, 절벽) 높이로 채우던 것을, 물가 높이의 평면으로 덮음. 수면 안에 3D 점이 거의 없고 주변보다 높지 않을 때만 수면으로 확정하므로 청록 지붕 같은 곳은 대부분 걸러짐
  - 결과 칸에 적용 여부와 평면으로 처리한 수면 면적을 표시함. 판별 결과는 결과 폴더 `project/water/`에 저장되어 정밀 보정으로 다시 만들 때도 같이 쓰임
- 엔진 명령행 `ortho --water auto|on|off`

## 검증

- Mavic 2 Pro 해안 마을 13장(고도 150 m): 수면 1.55 ha를 평면으로 처리함. 추정한 수면 높이가 높이를 바꿔 가며 잰 영상 간 일관성의 최대점과 일치함
  - 연직 영상 2장의 화소 일관성(5×5 NCC 중앙값): 수면 0.780 → 0.833, 물가 10 m 띠 0.829 → 0.833, 육지는 그대로
- 수면이 없는 도심 공원 18장: 자동 판별로 꺼짐(수면 1.7%). 강제로 켜도 청록 지붕·그늘진 도로 일부(약 350 m²)만 후보로 잡혔고, 그 높이를 주변 높이로 잡아 결과 차이가 작음
- Aukerman 77장(수면 0.6%, 자동이면 꺼짐): 켜면 작은 연못 448 m²를 평면으로 처리함. 77장 모두 정합
- 판별 시간은 영상당 약 0.15초(2코어)

## 한계

- 화면 대부분이 수면인 영상은 여전히 정합되지 않을 수 있음. 정합 안 된 영상으로 빈 곳을 채우는 기능은 다음 단계로 검토 중
- 파도·반사광이 심한 수면, 탁한 물, 하늘이 비친 수면은 판별하지 못할 수 있음. 해당 데이터로는 아직 검증하지 않았음
- 다중분광 영상에는 아직 적용하지 않음

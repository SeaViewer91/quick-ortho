다중분광 카메라(MicaSense RedEdge·Altum 계열)를 지원하는 릴리스임. 밴드별 반사율 정사 모자이크와 식생지수(NDVI·NDRE·GNDVI)를 만듦.

## 설치 파일

| OS | 파일 |
|---|---|
| macOS 14 이상 (Apple Silicon) | `QuickOrtho_0.4.0_aarch64.dmg` |
| Windows 10/11 (64비트) | `QuickOrtho_0.4.0_x64-setup.exe` 또는 `QuickOrtho_0.4.0_x64_en-US.msi` |

설치 방법은 [사용 매뉴얼](https://github.com/SeaViewer91/quick-ortho/blob/main/docs/MANUAL.md)을 참고함. macOS는 설치 후 터미널에서 다음을 한 번 실행해야 함.

```bash
xattr -dr com.apple.quarantine /Applications/QuickOrtho.app
```

## 새 기능

- **다중분광 정사 모자이크**: MicaSense RedEdge-MX, RedEdge-P, Altum, Altum-PT의 밴드 TIFF 폴더를 그대로 불러와 처리함
  - 결과 `orthomosaic.tif`는 밴드별 반사율(float32)이고, `indices.tif`에 NDVI·NDRE·GNDVI를 함께 만듦
  - 지도에 반사율 컬러 미리보기와 `식생지수 (NDVI)` 레이어를 표시함
- **방사보정**: 제조사 공개 보정식으로 원시 값을 방사휘도로 바꾸고, 입사광 센서(DLS)와 패널 촬영으로 반사율을 구함. 패널은 카메라가 기록한 영역·기준 반사율을 자동으로 씀
- **밴드 정합**: 밴드마다 자기 카메라로 지형(DSM)에 직접 투영하고, 밴드 간 자세는 비행마다 영상으로 미세 조정함. 시험 데이터에서 밴드 간 어긋남 0.1화소 이하
- **캡처 간 반사율 보정**: 같은 지점을 본 캡처끼리 반사율을 맞춰, 구름·DLS 기울기로 생기던 캡처 경계 단차를 줄임 (시험 데이터에서 불일치 9~14% → 6~9%). 전체 반사율 수준은 DLS·패널 기준 그대로 유지

## 검증

- 공개 데이터: OpenDroneMap Bürgewald 부분집합(RedEdge-P 24캡처, CC0)으로 전체 처리를 확인함
- MicaSense 공개 예제(RedEdge-MX·RedEdge-P·Altum·Altum-PT)로 메타데이터와 패널 반사율 계산을 확인함
- 실제 업무 데이터로는 아직 검증하지 않았음

## 알려진 한계

- DJI Mavic 3M은 지원하지 않음 (예정)
- 패널 촬영이 없으면 폴더 불러오기의 촬영 범위가 대략값임 (정사 모자이크에는 영향 없음)
- Altum-PT 열적외 밴드는 출력하지 않음

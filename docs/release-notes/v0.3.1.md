v0.3.0의 심라인 합성에서 영상 경계마다 보이던 밝기 단차를 없앤 릴리스임.

## 설치 파일

| OS | 파일 |
|---|---|
| macOS 14 이상 (Apple Silicon) | `QuickOrtho_0.3.1_aarch64.dmg` |
| Windows 10/11 (64비트) | `QuickOrtho_0.3.1_x64-setup.exe` 또는 `QuickOrtho_0.3.1_x64_en-US.msi` |

설치 방법은 [사용 매뉴얼](https://github.com/SeaViewer91/quick-ortho/blob/main/docs/MANUAL.md)을 참고함. macOS는 설치 후 터미널에서 다음을 한 번 실행해야 함.

```bash
xattr -dr com.apple.quarantine /Applications/QuickOrtho.app
```

## 개선

- **영상 경계의 밝기 단차 제거**: v0.3.0부터 화소마다 영상 하나를 골라 붙이면서, 영상끼리 노출이나 태양 방향에 따른 지면 반사(모래사장, 잔디밭)가 다르면 경계를 따라 계단·다각형 모양의 밝기 차가 뚜렷하게 보였음. 정사투영 전에 `밝기·색 보정` 단계를 추가해 영상마다 완만한 밝기 보정 곡면을 구해 적용함. 밝기 차이만 넓은 범위에서 맞추고 세부 질감은 원래 영상 그대로 쓰므로 선명도는 유지됨
- 건물 옆면, 파도처럼 영상마다 보이는 내용이 다른 곳은 보정 계산에서 자동으로 빠져 색 얼룩이 생기지 않음
- 처리 시간 증가는 정사 모자이크 단계의 약 3~10% (Aukerman 77장 14초, Mavic 2 18장 3초)
- 정밀 보정에서 다시 만드는 정사 모자이크에도 적용됨

## 알려진 한계

- 고층 건물의 지붕선이 영상 경계에서 어긋나 보이는 것은 밝기가 아니라 간이 DSM의 높이 문제라 이번 보정으로 바뀌지 않음
- 엔진 명령행에서 `--no-color-balance`로 보정을 끌 수 있음

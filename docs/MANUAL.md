# QuickOrtho 사용 매뉴얼

현장에서 촬영한 드론 영상으로 촬영 상태를 확인하고 정사 모자이크(GeoTIFF)를 만드는 방법을 설명함.
설치 후에는 인터넷 없이 동작함.

## 1. 설치

[Releases](https://github.com/SeaViewer91/quick-ortho/releases) 페이지에서 최신 버전의 설치파일을 받음.

| OS | 파일 | 요구 사항 |
|---|---|---|
| macOS (Apple Silicon: M1 이상) | `QuickOrtho_<버전>_aarch64.dmg` | macOS 14(Sonoma) 이상 |
| Windows 10/11 (64비트) | `QuickOrtho_<버전>_x64-setup.exe` 또는 `.msi` | - |

### macOS

1. `.dmg`를 열고 QuickOrtho를 응용 프로그램 폴더로 끌어다 놓음
2. 코드 서명을 하지 않은 앱이므로 터미널에서 다음 명령을 한 번 실행함

   ```bash
   xattr -dr com.apple.quarantine /Applications/QuickOrtho.app
   ```

3. 응용 프로그램 폴더에서 QuickOrtho를 실행함

### Windows

1. `-setup.exe`(또는 `.msi`)를 실행함
2. "Windows의 PC 보호" 경고가 나오면 `추가 정보` → `실행`을 누름
3. Windows 10에서 WebView2 설치 안내가 나오면 설치함 (최초 1회, 인터넷 필요)

## 2. 화면 구성

- 왼쪽 패널: 영상 폴더 선택, 진행 상황, 촬영 상태, 정사 모자이크 결과, 레이어
- 오른쪽: 지도 (배경지도 없이 결과만 표시함)
- 하단: 앱 버전과 엔진 상태. `엔진 준비됨`이 표시되면 작업할 수 있음 (앱 시작 후 수 초 소요)

## 3. 사용 순서

### 3.1 영상 폴더 불러오기

`영상 폴더 선택`을 누르고 드론 영상(JPG)이 들어 있는 폴더를 고름.
1초 안팎으로 사진 정보(EXIF)를 읽어 다음을 표시함. 영상 자체는 이 단계에서 열지 않음.

- 지도: 영상별 촬영 범위(파란 사각형)와 촬영 위치(점)
- 촬영 상태: 누락 구역, 영상 수, 비행고도, 조사 면적, 중복 매수, 전방 중복률, 저중복 면적
- 경고: 롤링 셔터 카메라, 짐벌 방향 보정, 경사 촬영, GPS 없는 영상 등

`누락 구역 N곳`이 표시되면 지도에서 보라색으로 칠해진 곳을 확인하고, 철수 전에 재촬영을 검토함.

### 3.2 간이 모자이크 (선택)

`간이 모자이크 생성`을 누르면 수 초 안에 영상을 대략 배치한 모자이크를 보여줌.
촬영 범위와 대상이 제대로 찍혔는지 눈으로 확인하는 용도임.
사진 정보만으로 배치하므로 수 m 정도 어긋날 수 있음.

### 3.3 정사 모자이크

`정사 모자이크 생성`을 누르면 영상끼리 정합해 정사 모자이크를 만듦.
처리 시간은 영상 수와 노트북 사양에 따라 수십 초에서 수십 분이 걸림.
진행 중에는 `중단`으로 멈출 수 있음.

참고 처리 시간 (Mavic 2 Pro, 20MP)

| 장수 | 맥북 에어 M1 (8GB) |
|---|---|
| 18장 | 약 40초 |

완료되면 지도에 결과가 겹쳐 표시되고, 정합 수·GSD·재투영 오차·GPS 잔차가 표시됨.
`결과 폴더 열기`로 파일 위치를 열 수 있음.

이미 정사 모자이크를 만든 폴더를 다시 불러오면 이전 결과(보정 결과 포함)가 함께 표시됨.

### 3.4 정밀 보정 (GCP·타이포인트)

정사 모자이크 결과 패널의 `정밀 보정 (GCP·타이포인트)`를 누르면 보정 화면이 열림.
보정 화면에는 세 개의 탭(GCP, 타이포인트, 오차 정리)과 `보정 실행` 패널이 있음.
탭에서 한 수정은 바로 저장되며, `보정 실행`을 눌러야 정사 모자이크에 반영됨.

> 이 기능은 v0.2.0 이상에서 만든 정사 모자이크에서만 쓸 수 있음. 이전 버전의 결과는 정사 모자이크를 다시 생성해야 함.

#### GCP로 좌표 보정

1. `GCP` 탭에서 `측량 성과 파일 불러오기`를 누르고 측량 성과 파일(CSV, TXT)을 고름
2. 불러오기 창에서 다음을 확인함
   - 인코딩, 구분자: 자동으로 판단함. 한글이 깨지면 인코딩을 `CP949`로 바꿈
   - 열 지정: 점명, 동(E)·경도, 북(N)·위도, 표고 열을 고름.
     국내 측량 성과는 보통 X가 북(N), Y가 동(E)이므로 순서에 주의함
   - 좌표계: 촬영 지역과 비교해 자동으로 고름 (예: GRS80 중부원점 EPSG:5186). 목록에 없으면 EPSG 번호를 직접 입력함
3. 목록에서 점마다 역할을 정함
   - 기준: 보정에 사용함
   - 검사: 보정에 쓰지 않고 정확도 확인에만 사용함
4. 점명을 누르면 사진에서 위치를 표시하는 화면이 열림
   - 왼쪽에 이 점이 보일 것으로 예측되는 사진이 확대 조각으로 나열됨 (노란 십자선: 예측 위치)
   - 사진을 고르고 오른쪽 큰 화면에서 표적 중심을 클릭함 (초록 원: 표시한 위치)
   - 휠로 확대·축소, 끌어서 이동함. `다음 사진`으로 다음 후보 사진으로 넘어감
   - 2장 이상 표시하면 표시한 점들로 위치를 다시 계산해 나머지 사진의 예측이 정확해짐
   - 사진 이름 옆 숫자는 표시한 위치와 계산 위치의 차이(px)임. 다른 사진보다 크게 튀면 잘못 찍은 것이므로 다시 표시함
5. 권장 수량
   - 기준점 3점 이상 (조사 지역 외곽에 고르게 배치, 가능하면 5점 이상)
   - 점마다 사진 2장 이상, 가능하면 3~5장에 표시
   - 검사점 1~2점 이상

기준점 수에 따른 처리 방식

| 기준점 (사진 2장 이상 표시) | 처리 |
|---|---|
| 3점 이상 | GCP 좌표계로 맞춘 뒤 GCP를 고정해 번들 조정함. 기준점이 4점 이상이고 높이 차가 충분하면 카메라 초점거리·왜곡도 함께 조정함 |
| 1~2점 | GPS로 정렬한 뒤 GCP 평균 차이만큼 평행 이동만 함 |
| 0점 | 번들 조정 후 GPS로 다시 정렬함 |

GCP가 투영 좌표계(예: EPSG:5186)이면 보정 결과 정사 모자이크도 그 좌표계로 저장되고, 표고도 측량 성과의 높이 기준을 따름.

#### 수동 타이포인트

사진 경계에서 어긋나 보이는 곳, 특징이 적어 정합이 약한 곳의 연결을 보강함.

1. `타이포인트` 탭에서 `새 타이포인트`를 누르고 지도에서 위치를 클릭함
2. 그 위치가 보이는 사진이 나열되면, 같은 지점을 사진 2장 이상에 표시함
3. 첫 사진에 표시하면 DSM으로, 2장 이상 표시하면 표시한 점들로 나머지 사진의 위치를 예측함

#### 오차 정리 (타이포인트 수정)

자동 정합된 타이포인트 중 오차가 큰 점을 지워 재투영 오차(RMSE)를 낮춤.

- 현재 타이포인트: 3D 점 수, 관측 수, 재투영 오차 RMSE와 분포를 보여줌
- 오차 큰 관측 자동 제거: 기준(px)을 고르면 그보다 오차가 큰 관측을 지움. 기준마다 지워지는 관측 비율과 예상 RMSE가 표시됨.
  권장 기준(관측 10% 이하 제거)을 참고함. 너무 많이 지우면 사진 간 연결이 약해져 정합이 오히려 나빠질 수 있음
- 오차 큰 점: 점별 오차 순으로 나열됨. 지도에서도 색(초록 작음 → 빨강 큼)으로 표시되며, 지도에서 점을 눌러 선택할 수 있음.
  선택한 뒤 `선택한 점 삭제`를 누름
- 사진별 오차: 오차가 큰 사진을 확인함. 특정 사진만 크게 높으면 흔들림·초점 불량 사진일 수 있음

#### 보정 실행과 결과

`보정 실행`을 누르면 수정 사항을 적용해 번들 조정을 하고 DSM과 정사 모자이크를 다시 만듦.
처리 시간은 정사투영 단계가 대부분이며, 최초 처리 시간의 약 25~35%임.

`마지막 보정 결과`에 다음이 표시됨.

- 방식, 좌표계, 재투영 RMSE 변화(보정 전 → 후), 3D 점 수 변화
- 기준점·검사점 RMSE (X, Y, Z, 3D, m)
- 점별 오차: dX, dY, dZ(m)와 사진 위 오차(px)

정확도는 기준점이 아니라 검사점 오차로 판단함. 기준점 오차만 작고 검사점 오차가 크면 표시 위치, 좌표계, 열 지정을 다시 확인함.

보정은 항상 최초 정합 결과에서 다시 시작하므로 여러 번 실행해도 결과가 누적되지 않음.
`최초 결과로 되돌리기`를 누르면 보정 전 정사 모자이크로 돌아감 (표시한 GCP와 수정 사항은 남아 있음).

### 3.5 레이어

`레이어`에서 간이 모자이크, 정사 모자이크, 중복도, 촬영 범위·위치, 누락 구역을 켜고 끔.
중복도 색: 빨강 1장, 주황 2장, 노랑 3~4장, 초록 5장 이상.

## 4. 결과 파일

영상 폴더 옆에 `<폴더명>_QuickOrtho` 폴더가 만들어짐.

```
<폴더명>_QuickOrtho/
├── preview/
│   ├── preview.geojson    촬영 범위·위치·누락 구역 (WGS84)
│   ├── coverage.png       중복도 지도
│   ├── quicklook.png      간이 모자이크 (생성한 경우)
│   └── preview.json       요약
└── ortho/
    ├── orthomosaic.tif    정사 모자이크 (Cloud Optimized GeoTIFF, RGBA)
    ├── dsm.tif            처리에 사용한 간이 DSM
    ├── preview.png        미리보기
    ├── report.json        처리 보고서 (정합 수, 오차, 단계별 시간, 메모리, 경고, 보정 결과)
    └── project/           정밀 보정용 정합 결과
        ├── edits.json     GCP, 사진 표시 위치, 타이포인트, 삭제한 점, 자동 제거 기준
        └── ...            최초·보정 정합 결과, 사진 조각 캐시
```

- 좌표계는 보정 전에는 WGS84 UTM, GCP로 보정하면 GCP 좌표계임
- `project/`를 지우면 정밀 보정을 쓸 수 없음. 정사 모자이크를 다시 생성하면 새로 만들어짐 (GCP 표시 위치는 유지됨)
- 결과 폴더와 원본 영상 폴더를 옮기면 보정 기능이 원본 사진을 찾지 못할 수 있음

`orthomosaic.tif`는 QGIS, ArcGIS 등에서 바로 열 수 있음.

## 5. 지원 기종과 정확도

- 검증 완료: DJI Mavic 2 Pro
- 지원 예정(검증 중): DJI Mavic 3E, Matrice 4E, Phantom 4 Pro V2.0
- 그 밖의 기종도 EXIF에 GPS가 있으면 처리할 수 있으나 검증하지 않았음

정확도와 한계

- GCP 없이는 절대 위치 정확도가 드론 GNSS 수준(수 m)임. 정밀 위치가 필요하면 3.4의 GCP 보정을 함
- 현장 확인용 간이 DSM을 사용하므로 고층 건물은 옆면이 보이거나 약간 겹쳐 보일 수 있음
- 수면, 모래사장처럼 특징이 없는 곳이 넓으면 정합에 실패하는 영상이 생길 수 있음
- Mavic 2 등 롤링 셔터 카메라는 빠른 속도로 비행하며 촬영하면 왜곡이 생길 수 있음. 저속 비행을 권장함

## 6. 문제 해결

| 증상 | 조치 |
|---|---|
| 하단에 `엔진 오류`가 표시됨 | 앱을 다시 시작함. 계속되면 오류 문구를 개발자에게 전달함 |
| macOS에서 "손상되었기 때문에 열 수 없습니다" | 1장의 `xattr` 명령을 실행함 |
| 폴더를 불러오면 `GPS 정보가 있는 영상이 없어` 오류 | GPS가 기록된 원본 JPG인지 확인함 (편집·변환한 사진은 EXIF가 빠질 수 있음) |
| 정사 모자이크에서 `정합된 영상이 3장 미만` 오류 | 영상 간 중복이 부족하거나 수면 위주 영상임. 중복도 지도를 확인함 |
| 처리가 매우 느림 | 다른 무거운 프로그램을 종료함. 맥북 에어는 발열로 속도가 떨어질 수 있음 |
| 정밀 보정에서 `보정용 프로젝트가 없음` | v0.1.0에서 만든 결과임. 정사 모자이크를 다시 생성함 |
| GCP 불러오기에서 좌표계를 자동 판단하지 못함 | 측량 성과의 좌표계를 직접 고르고, 동(E)·북(N) 열이 바뀌지 않았는지 확인함 |
| GCP 예측 위치가 표적과 수 m 어긋남 | 정상임 (드론 GPS 오차). 표적을 직접 찾아 표시하면 2장째부터 예측이 정확해짐 |
| 검사점 오차가 수 m 이상 | 열 지정(X·Y 순서), 좌표계, 표시 위치를 확인함 |

오류를 알릴 때는 화면의 오류 내용과 결과 폴더의 `report.json`(있는 경우)을 함께 전달함.

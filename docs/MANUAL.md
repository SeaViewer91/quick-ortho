# QuickOrtho 사용 매뉴얼

현장에서 촬영한 드론 영상으로 촬영 상태를 확인하고 정사 모자이크(GeoTIFF)를 만드는 방법을 설명함.
설치 후에는 인터넷 없이 동작함.

## 1. 설치

[Releases](https://github.com/SeaViewer91/quick-ortho/releases) 페이지에서 최신 버전의 설치파일을 받음.

| OS | 파일 | 요구 사항 |
|---|---|---|
| macOS (Apple Silicon: M1 이상) | `QuickOrtho_<버전>_aarch64.dmg` | macOS 14(Sonoma) 이상 |
| Windows 10/11 (64비트) | `QuickOrtho_<버전>_x64-setup.exe` 또는 `.msi` | - |

### macOS

1. `.dmg`를 열고 QuickOrtho를 응용 프로그램 폴더로 끌어다 놓음
2. 코드 서명을 하지 않은 앱이므로 터미널에서 다음 명령을 한 번 실행함

   ```bash
   xattr -dr com.apple.quarantine /Applications/QuickOrtho.app
   ```

3. 응용 프로그램 폴더에서 QuickOrtho를 실행함

### Windows

1. `-setup.exe`(또는 `.msi`)를 실행함
2. "Windows의 PC 보호" 경고가 나오면 `추가 정보` → `실행`을 누름
3. Windows 10에서 WebView2 설치 안내가 나오면 설치함 (최초 1회, 인터넷 필요)

## 2. 화면 구성

- 왼쪽 패널: 영상 폴더 선택, 진행 상황, 촬영 상태, 정사 모자이크 결과, 레이어
- 오른쪽: 지도 (배경지도 없이 결과만 표시함)
- 하단: 앱 버전과 엔진 상태. `엔진 준비됨`이 표시되면 작업할 수 있음 (앱 시작 후 수 초 소요)

## 3. 사용 순서

### 3.1 영상 폴더 불러오기

`영상 폴더 선택`을 누르고 드론 영상(JPG)이 들어 있는 폴더를 고름.
1초 안팎으로 사진 정보(EXIF)를 읽어 다음을 표시함. 영상 자체는 이 단계에서 열지 않음.

- 지도: 영상별 촬영 범위(파란 사각형)와 촬영 위치(점)
- 촬영 상태: 누락 구역, 영상 수, 비행고도, 조사 면적, 중복 매수, 전방 중복률, 저중복 면적
- 경고: 롤링 셔터 카메라, 짐벌 방향 보정, 경사 촬영, GPS 없는 영상 등

`누락 구역 N곳`이 표시되면 지도에서 보라색으로 칠해진 곳을 확인하고, 철수 전에 재촬영을 검토함.

### 3.2 간이 모자이크 (선택)

`간이 모자이크 생성`을 누르면 수 초 안에 영상을 대략 배치한 모자이크를 보여줌.
촬영 범위와 대상이 제대로 찍혔는지 눈으로 확인하는 용도임.
사진 정보만으로 배치하므로 수 m 정도 어긋날 수 있음.

### 3.3 정사 모자이크

`정사 모자이크 생성`을 누르면 영상끼리 정합해 정사 모자이크를 만듦.
처리 시간은 영상 수와 노트북 사양에 따라 수십 초에서 수십 분이 걸림.
진행 중에는 `중단`으로 멈출 수 있음.

참고 처리 시간 (Mavic 2 Pro, 20MP)

| 장수 | 맥북 에어 M1 (8GB) |
|---|---|
| 18장 | 약 40초 |

완료되면 지도에 결과가 겹쳐 표시되고, 정합 수·GSD·재투영 오차·GPS 잔차가 표시됨.
`결과 폴더 열기`로 파일 위치를 열 수 있음.

### 3.4 레이어

`레이어`에서 간이 모자이크, 정사 모자이크, 중복도, 촬영 범위·위치, 누락 구역을 켜고 끔.
중복도 색: 빨강 1장, 주황 2장, 노랑 3~4장, 초록 5장 이상.

## 4. 결과 파일

영상 폴더 옆에 `<폴더명>_QuickOrtho` 폴더가 만들어짐.

```
<폴더명>_QuickOrtho/
├── preview/
│   ├── preview.geojson    촬영 범위·위치·누락 구역 (WGS84)
│   ├── coverage.png       중복도 지도
│   ├── quicklook.png      간이 모자이크 (생성한 경우)
│   └── preview.json       요약
└── ortho/
    ├── orthomosaic.tif    정사 모자이크 (Cloud Optimized GeoTIFF, UTM 좌표계, RGBA)
    ├── dsm.tif            처리에 사용한 간이 DSM
    ├── preview.png        미리보기
    └── report.json        처리 보고서 (정합 수, 오차, 단계별 시간, 메모리, 경고)
```

`orthomosaic.tif`는 QGIS, ArcGIS 등에서 바로 열 수 있음.

## 5. 지원 기종과 정확도

- 검증 완료: DJI Mavic 2 Pro
- 지원 예정(검증 중): DJI Mavic 3E, Matrice 4E, Phantom 4 Pro V2.0
- 그 밖의 기종도 EXIF에 GPS가 있으면 처리할 수 있으나 검증하지 않았음

정확도와 한계

- 절대 위치 정확도는 드론 GNSS 수준(수 m)임. 정밀 위치가 필요하면 GCP 보정이 필요함 (현재 미지원)
- 현장 확인용 간이 DSM을 사용하므로 고층 건물은 옆면이 보이거나 약간 겹쳐 보일 수 있음
- 수면, 모래사장처럼 특징이 없는 곳이 넓으면 정합에 실패하는 영상이 생길 수 있음
- Mavic 2 등 롤링 셔터 카메라는 빠른 속도로 비행하며 촬영하면 왜곡이 생길 수 있음. 저속 비행을 권장함

## 6. 문제 해결

| 증상 | 조치 |
|---|---|
| 하단에 `엔진 오류`가 표시됨 | 앱을 다시 시작함. 계속되면 오류 문구를 개발자에게 전달함 |
| macOS에서 "손상되었기 때문에 열 수 없습니다" | 1장의 `xattr` 명령을 실행함 |
| 폴더를 불러오면 `GPS 정보가 있는 영상이 없어` 오류 | GPS가 기록된 원본 JPG인지 확인함 (편집·변환한 사진은 EXIF가 빠질 수 있음) |
| 정사 모자이크에서 `정합된 영상이 3장 미만` 오류 | 영상 간 중복이 부족하거나 수면 위주 영상임. 중복도 지도를 확인함 |
| 처리가 매우 느림 | 다른 무거운 프로그램을 종료함. 맥북 에어는 발열로 속도가 떨어질 수 있음 |

오류를 알릴 때는 화면의 오류 내용과 결과 폴더의 `report.json`(있는 경우)을 함께 전달함.
